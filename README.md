# Aero-Flask Enterprise: Airline Management System

An enterprise-grade, Flask-based Airline Management and Reservation System built for academic evaluation covering full-stack web development with Flask, SQLAlchemy ORM (40+ models), Jinja2 templating, server-side forms, session authentication, and soft-delete capabilities.

## Tech Stack
- **Backend**: Python 3, Flask
- **ORM & Database**: Flask-SQLAlchemy (PostgreSQL / SQLite)
- **Forms & Validation**: Flask-WTF, WTForms
- **Templating**: Jinja2
- **Deployment**: Render (Gunicorn)
